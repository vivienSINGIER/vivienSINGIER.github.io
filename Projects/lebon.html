À propos

OBJ. 01

Le langage

Lebon est un langage avec fonctions, récursion et closures, dont les mots-clés sont en créole : keksoz déclare une variable, kan ouvre une condition et zafer définit une fonction. Le projet a été réalisé à 3 développeurs.

OBJ. 02

La chaîne d'exécution

Le code passe par un lexer, un parser qui construit un AST, puis une analyse sémantique. Il peut ensuite être exécuté de trois façons : un interpréteur Tree Walking, une VM à registres sur bytecode, ou un JIT qui génère du code machine x86-64 en mémoire exécutable. Sur fibo.lbn, en médiane sur 100 exécutions, la VM est 16,6 fois plus rapide que le Tree Walking et le JIT 48,9 fois.

OBJ. 03

Ma contribution

J'ai réalisé le lexer, l'analyse sémantique et le compilateur JIT. Le gain du JIT dépend fortement du programme : il n'est que de 1,3 fois face à la VM sur cordes.lbn, un benchmark centré sur les chaînes. Le langage n'a pas de ramasse-miettes, toute la mémoire vit aussi longtemps que le heap.
