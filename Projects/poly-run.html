Poly Run

Un prototype de Runner en 3D fait avec une librairie 3D expérimentale.

MVC - Model View Controller Gameplay C++
Project Repo →
// POLY_RUN_MAIN [stable]

A propos

L'objectif du projet était de produire un prototype de jeu du type Runner en 3 dimensions en appliquant une architecture MVC (Model-View-Controller).

Pour mener à bien le projet, j'ai dû rajouter une couche moteur par-dessus la librairie de rendu. Celle-ci possédait beaucoup de problèmes que je ne pouvais régler, j'ai donc essayé de les contourner.

On peut aussi y trouver des fonctionnalités gameplay interressantes comme les tweens, des outils d'interpolation permettant des transitions propres sur les mouvements des objets. Le jeu contient 3 biomes avec obstacles qui leur sont propres, ainsi qu'une mécanique d'inversion de gravité.
